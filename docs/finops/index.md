# FinOps & CCM Reports

> Cloud cost analysis, anomaly investigations, budget health reviews, and commitment orchestration reports.

## Available Reports

    FinOps reports will appear here as they are generated by the Harness CCM FinOps Agent.

---

## Report Types

| Type | Description | Typical Cadence |
|---|---|---|
| **Monthly Cost Review** | Full spend breakdown by cloud, BU, service | Monthly |
| **Budget Health Report** | Budget vs actuals, at-risk budgets, forecast | Weekly |
| **Anomaly Investigation** | Root cause analysis for cost spikes | On-demand |
| **Commitment Orchestration Review** | RI/SP coverage, savings, utilisation | Monthly |
| **BVR (Executive)** | Full business value review for stakeholders | Quarterly |
| **Spike Triage** | Day-of investigation for cost spikes | On-demand |

---

## Generating a FinOps Report

Use the Harness CCM FinOps Agent in Cursor:

```
Generate a monthly FinOps report for [account/perspective] for [month/year].
Include: spend breakdown, budget health, top anomalies, recommendations,
and commitment orchestration summary. Save to the knowledge base.
```

See [How to Add Reports](how-to-add.md) for the publishing workflow.
