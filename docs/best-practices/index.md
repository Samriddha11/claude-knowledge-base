## Contributing

Best practices documents should:

1. Be based on real-world observations or industry standards
2. Include concrete examples (YAML, code snippets, diagrams)
3. Have a clear maturity model or self-assessment
4. Reference their source (account analysis, DORA, NIST, etc.)

See the [Contributing Guide](../how-to-contribute.md) for publishing instructions.
