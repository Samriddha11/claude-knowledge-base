# Business Value Reviews

> Claude-generated BVR reports for customer accounts and internal reviews.

## What is a BVR?

A **Business Value Review (BVR)** is an executive summary document that demonstrates the value delivered by the Harness platform to a customer account. BVRs are generated by the Harness CCM FinOps Agent using live account data and published here for internal reference.

---

## BVR Report Structure

Each BVR typically covers:

| Section | Content |
|---|---|
| Executive Summary | Top-line metrics, savings achieved, platform ROI |
| Cost Breakdown | Spend by cloud, business unit, and service |
| Budget Health | Budget vs actuals, at-risk budgets |
| Anomalies | Detected anomalies and root cause |
| Recommendations | Open savings opportunities |
| Commitment Orchestration | RI/SP coverage, savings, utilisation |
| Next Steps | Action items for the account team |

---

## Generating a BVR

Use the Harness CCM FinOps Agent in Cursor with the following prompt:

```
Generate a BVR for [customer name] covering [time period].
Include: cost breakdown by business unit, budget health status,
top anomalies, open recommendations, and commitment orchestration summary.
Output as a formatted report and publish to the knowledge base.
```

See [How to Add a BVR](how-to-add.md) for the publishing workflow.
