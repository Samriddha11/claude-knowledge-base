## How This Works

```
Claude AI / Harness Agent
         │
         │ generates markdown report
         ▼
  Harness CCM FinOps Agent
  (harness_ccm_finops_report_render)
         │
         │ commit to this repo  ──►  GitHub PR
         ▼
  claude-knowledge-base/docs/
         │
         │ TechDocs build
         ▼
  Harness IDP Portal  ◄──  You are here
```

Every document in this portal was generated by a Harness AI agent analysing real account data, then published here for the team to reference.

## Adding a New Document

See the [Contributing Guide](how-to-contribute.md) for how to add Claude artifacts to this portal.
Quick version:

1. Generate report using Harness Agent or Claude
2. Save as `.md` in the correct `docs/` subfolder
3. Add entry to `mkdocs.yml` nav
4. Open a PR — TechDocs rebuilds automatically on merge
