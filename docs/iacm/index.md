## About IaCM Documentation

These documents are generated by the **Harness IaCM Agent** — an AI agent that connects to your Harness account, analyses live pipeline configurations, and produces actionable recommendations and frameworks.

### How Documents Are Generated

```
Harness IaCM Agent (Cursor)
        │
        ├─ Fetches pipeline YAMLs via Harness API
        ├─ Analyses stages, steps, security integrations
        ├─ Cross-references with industry best practices
        └─ Generates structured markdown report
                │
                ▼
        Committed to this repo → Published in IDP
```

### Key Topics Covered

- **Pipeline Design** — unified lifecycle, per-action, multi-stage patterns
- **Security Scanning** — Wiz IaC, Checkov, tfsec, Harness STO integration
- **State Management** — backends, locking, disaster recovery
- **Workspace Governance** — naming, RBAC, lifecycle management
- **Cost & FinOps** — Infracost integration, tagging strategy, AutoStopping
- **Developer Experience** — self-service, golden path, module library
